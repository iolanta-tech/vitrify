# :material-download: Installation

`vitrify` is a Cargo package. Install [Rust](https://www.rust-lang.org/tools/install) 1.88 or newer, then install the package from [crates.io](https://crates.io/crates/vitrify):

```sh
cargo install vitrify
```

Cargo puts the `vitrify` command on `PATH`. This prints the installed version:

```sh
vitrify --version
```
