    Parse and write YAML-LD with saphyr

    Decided · 8 November 2026

    Context

    Vitrify parses and writes YAML-LD. That library follows YAML 1.2.

    Decision

    Alternative YAML 1.2 Decision
    saphyr-rs/saphyr Chosen
    Ethiraric/yaml-rust2 Not selected
    recursive-ai-oss/oneyaml-rust Not selected
    bourumir-wyngs/serde-saphyr Not selected
    acatton/serde-yaml-ng YAML 1.1 only.
    yaml/yaml-serde YAML 1.1 only.
    cafkafk/serde-norway YAML 1.1 only.
    dtolnay/serde-yaml Archived.
    sebastienrousseau/serde_yml Deprecated.
