    Examples

    Each example shows a saved SPARQL query, a preview of its response, and the files Vitrify wrote. Open a file link in the directory preview to inspect the captured source, response, or RO-Crate metadata.

    Query from a file is probably the most production-ready approach: the query can be versioned and reused in a pipeline. The other examples use echo and standard input to keep their commands self-contained.

    • Female Nobel laureates — a CSV result table from Wikidata.
    • EU capitals — five English capital labels in CSV.
    • Query from a file — save the EU-capitals query, then run it with --query query.rq.
    • Top ten metaclasses — metaclasses ranked by direct instance counts in QLever.
    • Metaclasses of metaclasses — metaclasses whose recorded instances are all metaclasses, with example instances.
    • Fourth-order classes — all items explicitly typed as fourth-order classes.
    • Time-bounded subclasses — a JSON result table with subclass intervals.
    • SELECT response returned as JSON — a format negotiation example where the endpoint returned JSON despite a Turtle request.
