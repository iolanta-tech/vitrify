    Query from a file

    Save as query.rq

    PREFIX wd: <http://www.wikidata.org/entity/>
PREFIX wdt: <http://www.wikidata.org/prop/direct/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?label
WHERE {
  ?country wdt:P463 wd:Q458 ;
           wdt:P36 ?capital .
  ?capital rdfs:label ?label .
  FILTER(LANG(?label) = "en")
}
ORDER BY ?label
LIMIT 5

    Run the query

    vitrify sparql --endpoint https://query.wikidata.org/sparql \
  --query query.rq \
  --format csv \
  --to eu-capitals

    This runs the same query as EU capitals.
